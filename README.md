# Angular Interactive Product Configurator

An interactive web application for complex parametric configuration, built with Angular using modern reactive programming paradigms, a Signals-driven state architecture, and advanced processing of nested data structures.

### Key Features
* **Complex Business Logic Engine:** Processing multi-level nested JSON structures, dynamic dependency chains between parameters, conditional validation, and real-time complex pricing calculations.
* **Signals-Based State Architecture:** Implementing predictable application state management utilizing Angular services and Signal primitives, ensuring business logic isolation and clean data flow.
* **Modern Reactivity & Change Detection Optimization:** Leveraging computed and effect primitives for granular reactivity, efficient derivation of computed data, and minimizing redundant change detection cycles.
* **Backend Integration:** Interfacing with a Node.js / Express.js backend via a typed HttpClient for asynchronous configuration loading and data serialization during order placement.
* **Modern Angular Architecture Patterns:** Strict separation of concerns, modular design, adherence to dependency injection principles, and reusable reactive patterns.

### Tech Stack
* **Frontend:** Angular, TypeScript
* **Build Tool:** Vite
* **State Management & Reactivity:** Angular Signals, Angular Services
* **Networking:** Angular HttpClient
* **Routing:** @angular/router
* **Styling:** SCSS
* **Backend:** Node.js, Express.js
