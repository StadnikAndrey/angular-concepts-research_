# Angular-concepts-research

The project was created to explore the basic concepts of Angular.

## Core Implementations:

### Routing
Implemented with @angular/router.

### Application state management
Implemented with Angular service + Signals.
The notification system has been implemented for the entire application.

### Data reactivity
Implemented with: HTTP client, Angular Signals.
A component with a large volume of interdependent data that can be modified by the user has been implemented.

### In the process of implementation:
Authentication and authorization system.
